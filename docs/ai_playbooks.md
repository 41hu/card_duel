# 人机 AI 角色出牌逻辑（Playbook）设计文档

> 目标：逐个为 15 名角色构建人机 AI 出牌逻辑，**决策必须考虑自定义卡组构成**（AI 读自己的 40 张构筑调整打法），避免玩家感觉「打木桩」。
>
> 流程（每角色）：**定位与打法设计 → 用户确认/修正 → 实现 playbook → 联调测试 → 下一个**。
> 设计确认前不实现；测试意见通过本文件持续修订。

## 架构

- **通用层**（已有，保留）：打分制动作评估（攻击/移动/响应/资源），按难度四档缩放
- **技能决策层**（新增）：每角色一个「打法函数」（skill playbook），独立于通用打分给出技能动作候选（带优先级），通用层取两者最高分
- **卡组感知**：AI 读自己的 `card_systems[idx].deck`（自定义卡组时 = 玩家构筑的 40 张），统计卡型构成 → 影响打法风格
- **风格参数表**（全部完成后叠加）：激进度/防御性等微调，不承载技能逻辑

## 猎人（第一版设计，2026-08-23）

### 定位

**中远程输出 + 控场布防者**。面板远 5 > 近 4，核心输出远程风筝；近 4 不弱，距离管理（保持 2-4 格）比纯远/纯近重要。「埋伏」不耗攻击点 = 每回合一个免费动作，夹子既是防守工事也是进攻封锁。

### 打法核心

1. **距离管理**：近战流对手 → 保持 2+ 格，被贴脸优先后撤；远程/魔法对射 → 按面板优劣势决定贴脸压制还是保持距离；对快枪手/神射手（远 6）→ 拉近距离用近 4 打
2. **埋伏/夹子决策**：
   - 防守布防：近战对手距离 ≤3 时在自己身前一格放夹子（贴身必经路）；被贴脸放身后脱身路线
   - 进攻封锁：对手被夹在板边两格之间时封死退路
   - 混放陷阱+夹子：**已验证「防拆」判断错误**——destroy_item_at 会同时按各类型规则拆除（陷阱拆1+夹子全清），混放无防拆效果；但混放 = 踩上 -6 双倍伤害区（陷阱3+夹子3），作为高威胁格用（**是否让 AI 追求双倍区，待确认**）
   - 时机：对手即将贴身时最高优先；远程对射时夹子价值低
   - 资源：远程/穿心卡存量 >4 才舍得埋伏（否则留输出）
   - 免疫站桩：**已验证可行**（对手贴脸踩上夹子 -3 后再攻击）——可站夹子格上等对手贴脸（**待确认**）
3. **输出**：远程 > 穿心 > 近战（面板+距离决定）

### 决策伪代码（实现蓝本）

```
_hunter_playbook(player_idx):
  卡组构成 = 统计自己的 deck 卡型（战术卡数/攻击卡数/有无远程牌）
  风格 = 战术流(陷阱/吸引/威慑/移动≥6) | 输出流(攻击≥22) | 纯近战(无远程)
  if 风格 != 纯近战 and 手牌有 range/pierce:
    夹子价值 = 0
    if 近战对手 and 距离≤3: 价值 += 12   # 防守布防
    if 距离≤1: 价值 += 6                 # 已贴脸：放身后脱身路线
    if 对手在板边: 价值 += 8              # 封锁退路
    if 战术流: 价值 += 4                  # 卡组定位加成
    if 资源不足(手牌远程<2 且 牌堆远程<4): 价值 = 0  # 留输出
    if 价值 > 0: 候选 = 埋伏(选夹子位置)
  距离管理（并入通用位移，增强版）：
    近战对手: 保持≥2格
    远程对手且我方远5<对方远6: 拉近到2格用近4
  免疫站桩: 若夹子格在自己与对手之间且对手近战型: 移动站上夹子格（待确认）
```

### 自定义卡组感知

- 战术卡多（陷阱/吸引/威慑/移动 ≥6）→ 「夹子封锁流」：多埋伏、主动封路
- 攻击卡多（≥22）→ 「远程输出流」：只防守性放夹子
- 卡组无远程/穿心 → 埋伏不可用，纯近战猎人（近 4 + 移动拉扯）

### 概念澄清（避免混淆）

- **道具卡** = 卡牌 type_id `trap`（手牌打出，耗 1 功能点）
- **地格道具类型** = 道具卡放置到棋盘上的实体：`trap`(普通陷阱) / `snare`(捕兽夹) / `torii`(鸟居)
- **角色决定道具类型**：猎人→捕兽夹(snare)、巫女→鸟居(torii)、其他→普通陷阱(trap)
- 因此「猎人的道具卡 = 捕兽夹」：夹子区 = 埋伏夹子 + 道具卡夹子叠放；摧毁卡拆夹子 all（一张清光同格）→ 夹子**分散布防优于集中**

### 推荐自定义卡组（道具流，40 张，B 套餐，已验证合法）

**攻击池 15**：range ×6（主力输出+牵制响应+埋伏素材）｜ pierce ×2（强化远程，埋伏放 2 夹子）｜ magic ×3（闪避响应防身）｜ near ×3（贴脸近 4 输出+格挡响应）｜ heavy ×1（贴脸爆发）

**战术池 14（道具流核心）**：**trap ×5**（上限 5，铺夹主力——道具卡耗功能点但不牺牲输出，比埋伏划算）｜ move ×3（风筝保距）｜ attract ×3（**拉进夹子区联动**）｜ deter ×2（推走保距）｜ freeze ×1（冻结风筝）

**回复数值池 6（B）**：heal_5 ×1 + heal_3 ×2（回 11）｜ range_buf ×1（远程+1 核心）｜ magic_buf ×1 ｜ near_buf ×1

**装备池 5**：range_weapon ×3（武器幻化）｜ range_armor ×1（防对射）｜ magic_armor ×1（防魔法——猎人魔 2 无抵抗）

**武器幻化池推荐**：远程 = 长弓（+1 距离衰减-1，核心）、**风神弓**（穿心命中控位移→推进夹子区，与夹子联动强，需手动换入）、毒牙（DoT）、鹰眼（看手牌）；近战/魔法默认即可

**打法闭环**：前中期道具卡+埋伏铺夹子（5+2 ≈ 7-9 个夹子/局，分散布防）→ attract 拉对手进夹子区 → 远程输出收割 → 被贴脸 freeze/near 应对 → 法术防具挡魔法。
